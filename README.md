# Red Sapien · Servicios profesionales

Landing page mobile-first para `https://profesionales.redsapien.com/`.

- Fuente: `index.html` (HTML, CSS y estilos inline; sin bibliotecas JavaScript externas).
- Casos: capturas auténticas de Carolina Ruiz Psico Spa, Noir Elixir y Adme Dental.
- Publicación: GitHub Pages, rama `main`, raíz `/`.
- DNS: `profesionales.redsapien.com` como CNAME DNS-only a `redsapien.github.io`.
